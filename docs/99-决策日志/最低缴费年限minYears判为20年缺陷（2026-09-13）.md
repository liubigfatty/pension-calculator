# 缺陷：最低缴费年限被判 20 年（应为 15 年）

> 发现：2026-09-13 · 跑「吉林 15 年最低年限 100 档 vs 300 档」时触发
> 状态：**✅ 已于 2026-09-14 修复并部署**（方案 A：正确表提升为引擎默认，与「未来年份外推值」合并处理，共用一个部署窗口）
> 验证：`scripts/_verify_base_growth.js` 第 5 节 —— 2024/2025/2029→15、2030→15.5、2031→16、2035→18、2038→19.5、2039/2045→20，**31/31 省一致**；
> `scripts/_verify_minyears.js` 第 11 节由 🚩 红灯转 ✅。

## 一、现象

男职工 1965-09 生、2010-12 参工、2025-12 退休，缴费 15 年整：

```
legal.minYears = 20
legal.meetMin  = false
```

网页端 `web/app.js:314`：

```js
$('minYears').textContent = fmtYears(sc.minYears) + (sc.meetMin ? ' ✓ 已满足' : ' ✗ 不足')
$('minYears').style.color = sc.meetMin ? 'var(--green)' : 'var(--red)'
```

⇒ 页面显示 **「最低缴费年限要求 20 年 ✗ 不足」**（红色）。这是错的。

## 二、政策依据

《国务院关于渐进式延迟法定退休年龄的办法》第二条：

> 从 2030 年 1 月 1 日起，将职工按月领取基本养老金最低缴费年限由十五年逐步提高至二十年，每年提高六个月。

人社部《关于延迟法定退休年龄的 30 个问答》第 11、12 条：

> **2029 年 12 月 31 日前，职工按月领取基本养老金最低缴费年限仍为 15 年。**
> 2025 年 1 月 1 日至 2029 年 12 月 31 日期间的最低缴费年限不调整，仍为 15 年。

正确取值表：

| 退休年份 | 最低缴费年限 |
|---|---|
| ~2024 | 15 |
| **2025–2029** | **15** |
| 2030 | 15.5 |
| 2031 | 16 |
| 2032 | 16.5 |
| 2033 | 17 |
| 2034 | 17.5 |
| 2035 | 18 |
| 2036 | 18.5 |
| 2037 | 19 |
| 2038 | 19.5 |
| 2039+ | 20 |

## 三、根因

`engine/pension-engine.js` 的 `getMinYears()`：

```js
function getMinYears(retireYear, config) {
  const minYearsTable = config.min_years || {}
  if (minYearsTable[retireYear] !== undefined) return minYearsTable[retireYear]

  // 默认逻辑
  if (retireYear < 2025) return 15
  return 20          // ← 2025 年起一律 20 年，跳过了 2025-2029 的 15 年和 2030-2038 的渐变
}
```

**只有四川配了 `min_years`**（`provinces/sichuan.js` 的 `MIN_YEARS_CONFIG`，内容完全正确：2025-2029=15 / 2030=15.5 / … / 2039+=20）。其余 **30 个省没配，全部走错误默认**。

推测是当初做四川订正时把正确表写在了省配置里，没提升为引擎默认。

## 四、影响面

| 维度 | 情况 |
|---|---|
| 错误省份 | **30 / 31**（仅四川正确） |
| 错误年份 | 2025–2029 退休（应为 15，判成 20）+ 2030–2038 退休（应渐变，判成 20） |
| 受影响用户 | 达到法定退休年龄、但缴费年限在 **15 ~ 20 年之间**的人，被误标「✗ 不足」 |
| 前端表现 | 网页端红色标注；小程序端当前**未消费**该字段（`miniprogram/` 无 `minYears`/`meetMin` 引用），故小程序无可见影响 |
| 金额计算 | **不受影响**——`minYears` 只做达标提示，不进入养老金公式 |

## 五、修法（与「未来年份外推值」同类，可合并处理）

**方案 A（推荐）：把正确表提升为引擎默认**

```js
function getMinYears(retireYear, config) {
  const t = config.min_years || {}
  if (t[retireYear] !== undefined) return t[retireYear]
  if (retireYear <= 2029) return 15
  if (retireYear >= 2039) return 20
  return 15 + (retireYear - 2029) * 0.5   // 2030→15.5 … 2038→19.5
}
```

改完可顺手把四川的 `MIN_YEARS_CONFIG` 删掉（与引擎默认重复，且只覆盖到 2045）。

**改动范围**：7 份引擎副本（同 P3 流程）+ `scripts/build-web.js` 重建 + 云函数 `calculate` 重新部署。

**方案 B：只改网页端文案**——治标，不推荐。
