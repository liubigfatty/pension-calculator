## 二、云函数部署（不需提审，随时可做）

### 2.1 `calculate`（主程序）

**为什么必须部署：**

1. **🔴 贵州独生子女增发 bug（线上现网错误）**：独立分支漏判 `data.oneChild`，导致**默认给每位贵州用户发 248.70 元/月**，且传 `oneChild:false` 关不掉。已修复（L1985 加 `&& data.oneChild`），回归 35/41 → 41/41。
2. **31 省社平语义统一**：个账储存额变化 6~8%。
3. **22 省 2026 年度社平入库**。

**不部署的后果**：线上贵州用户继续看到虚高 248.70 元/月的结果。

### 2.2 `calcIndex`（指数小程序）

分母取数索引 +1（数组右移联动）+ 31 省数据语义统一。**必须与前端 v2.1.7 配套**，否则前端新数据与旧云函数口径不一致。

### 2.3 部署命令

```bash
# 前置：必须先打开微信开发者工具、开启服务端口（CLI 不会冷启动 IDE）
cli cloud functions deploy --project <仓库根> --names calculate
cli cloud functions deploy --project <仓库根> --names calcIndex
```

⚠️ 红线（2026-09-09 事故后立）：

- `--project` 必须是**仓库根**（根 `project.config.json` 声明 `cloudfunctionRoot`）。
- `deploy` 用 `--names`（复数），值直接写，**不要写 JSON 数组**。
- 纯计算函数（`calculate`/`calcIndex`）已剥离 `wx-server-sdk`，**可安全 CLI 部署**。
- 其余 5 个（createOrder / getPaymentParams / payCallback / getQRCode / generateReportImage）**绝不能裸 CLI deploy**，必须走 IDE「上传并部署：云端安装依赖」。
- **部署后必须验证**：`cloud functions download` 拉回副本，逐省 `require('./index.js')` 跑一遍。deploy 日志 success ≠ 线上正确。
