# 对账：个人账户「引擎高估约 10%」到底成不成立

> 触发：真实数据（吉林松原，1995-07~2025-01）验收时，引擎输出个账 **189,339**，
> xlsx 末尾汇总行 **171,463**，差 +10.4%。当时记为「🔴 个账高估约 10%，疑早期个人比例非一律 8%」。
> 日期：2026-10-30 ｜ 结论：**不成立**。那是口径错配；真实偏差是**反向、且只有 1.2%**。

---

## 一、xlsx 那三个数到底是什么

《副本个人缴费信息查询.xlsx》是**缴费流水**，不是**账户台账**。列含义：

| 列 | 含义 |
|---|---|
| D | 费款所属期（缴费发生月） |
| **E** | **对应费款所属期**（真正归属的缴费月，引擎按此聚合） |
| F | 缴费基数 |
| G | 缴费类型（正常应缴 221 条 / 个人补收 113 条） |
| H | 单位应缴金额 |
| **I** | **个人应缴金额（本金）** |
| K | 个人应缴金额利息（补收产生的滞纳性质利息，**不是记账利息**） |

末尾三行：

```
行 345  I = 171463.29      ← 个人应缴金额本金合计
行 346  I =  47053.04      ← 性质待核（疑记账利息或单位划入）
行 347  I = 218516.33      ← 345 + 346，总计
```

### 171463.29 精确复算吻合

```
  334 条数据行（199401~202311）  I 合计      147,849.25
+ 2023-12 补记                                1,168.00
+ 2024-01 补记                               18,214.08
+ 2025-01 补记                                1,193.28
+ 行 343 / 行 344                          1,518.84 + 1,519.84
────────────────────────────────────────────────────────
                                            171,463.29   ✅ 逐位吻合
```

**⇒ 171,463.29 是「个人实缴本金合计」，不是个人账户储存额。**
拿账户储存额（189,339）去比实缴本金（171,463），差 10% 是必然的——因为账户里还有 28 年的记账利息。

## 二、逐年实测：个人缴费比例根本不是一律 8%

| 年份 | 实测个人缴费比例 | 说明 |
|---|---|---|
| 1995–1997 | **2%** | 建账初期（吉林执行值低于国标 3%） |
| 1998 | **4%** | 国发〔1997〕26号 |
| 1999–2000 | **5%** | |
| 2001–2002 | **6%** | |
| 2003 | **7%** | |
| 2009–2011 | **20%** | 灵活就业，单位部分为 0 |
| 2012 | 12.26% | 职工+灵活就业混合年 |
| 2020 | 10.93% | 混合 |
| 2013 起（职工） | **8%** | |

⚠️ 但**个人掏多少 ≠ 账户记多少**：
- 灵活就业缴 20%，只有 **8%** 进个人账户（国发〔2005〕38号），12% 进统筹；
- 1995-07~1997 账户记 **16%**、1998~2005 记 **11%**（含单位划入，国发〔1995〕6号／〔1997〕26号）。

## 三、真实偏差：不是高估 10%，是**低估 1.2%**

按吉林历年**记账**比例（16% / 11% / 8%）重算记入本金：

| 口径 | 记入本金 |
|---|---|
| 吉林实际（1995-97 16%、1998-2005 11%、2006 起 8%） | **133,626.91** |
| 引擎现口径（一刀切 8%） | 131,985.91 |
| **差** | **+1,641.00（引擎少记 1.2%）** |

原因：1995–2005 年本人缴费基数只有 43,592 元（占比极小），
所以 16%/11% 的溢价只值 1,641 元——**对月养老金的影响约 1641÷170 ≈ 9.6 元/月**。
