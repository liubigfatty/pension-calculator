## 一、xlsx 里的数到底是什么（只读结论）

《副本个人缴费信息查询.xlsx》是**缴费流水**，不是**账户台账**：

| 列 | 含义 |
|---|---|
| D | 费款所属期（缴费发生月） |
| **E** | **对应费款所属期**（真正归属的缴费月，引擎按此聚合） |
| F | 缴费基数 |
| G | 缴费类型（正常应缴 221 条 / 个人补收 113 条） |
| H | 单位应缴金额 |
| **I** | **个人应缴金额（本金）** |
| K | 个人应缴金额利息（补收滞纳性质，**不是记账利息**） |

- `171,463.29` = I 列本金合计，精确复算逐位吻合（147,849.25 + 1,168 + 18,214.08 + 1,193.28 + 1,518.84 + 1,519.84）。
- ⛔ `47,053.04` / `218,516.33` **一律不作依据**。

⚠️ 关键区分：**个人掏多少 ≠ 账户记多少**。灵活就业缴 20%，只记 8%；早期账户记 16%/11%（含单位划入）。所以 I 列本金与账户储存额之间不存在固定换算关系。

## 二、吉林个人账户记账比例——省级明文（三段）

| 时段 | 记账比例 | 出处 |
|---|---|---|
| 1995-07-01 ~ **1998-06-30** | **16%** | 吉政发〔1998〕22号《吉林省统一企业职工基本养老保险制度实施办法》四(一)3：「1995年7月1日至1998年6月30日个人账户的记账比例按缴费基数的16%计算」 |
| **1998-07-01** ~ 2003-12-31 | **11%** | 同上：「1998年7月1日以后个人账户的记账比例按个人缴费基数的11%计算」；配套「从1998年7月1日起按个人缴费工资的7%划入，个人缴费比例每增加1个百分点，划入部分相应降低1个百分点，最终达到3%」 |
| **2004-01-01** 起 | **8%** | 吉政发〔2004〕28号 二：「从2004年1月1日起……参保人员个人按本人缴费工资的8%缴纳基本养老保险费，并全部记入个人账户。个人账户规模由本人缴费工资的11%调整为8%」（国函〔2004〕35号试点） |

🔴 **分界点必须精确到月**：1998 年 1–6 月仍按 16%、7–12 月按 11%。按年取整会错。

**交叉印证**（xlsx 逐年实测个人缴费比例）：1995-97 缴 2%、1998 缴 4%、1999-2000 缴 5%、2001-02 缴 6%、2003 缴 7%、2013 起缴 8%。
按吉政发〔1998〕22号的「个人缴费 + 单位划入 = 11%」规则：2%→(建账期16%)、4%+7%=11%、5%+6%=11%、6%+5%=11%、7%+4%=11%、8%+0=8% —— **逐年对得上**。

## 三、全国：8% 起点的三个批次

个人账户规模 11%→8%，全国不是同一天：

| 批次 | 省份 | 8% 起点 | 出处 |
|---|---|---|---|
| 第一批（试点） | **辽宁** | **2001-07-01** | 辽政发〔2001〕24号 二、四；国务院批复辽宁试点方案（国函〔2001〕）；辽宁省人社厅《辽宁试点前后基本养老保险个人账户有什么不同?》 |
| 第二批（试点） | **吉林**、**黑龙江** | **2004-01-01** | 吉政发〔2004〕28号 二；国函〔2004〕35号（吉）、国函〔2004〕36号（黑） |
| 第三批（全国） | 其余 28 省 | **2006-01-01** | 国发〔2005〕38号 六 |

更早一段（11% 之前）：辽宁人社厅口径为 **1996-01-01~1997-12-31 记 12%、1998-01 起 11%**；吉林为 **1995-07~1998-06 记 16%**。
⚠️ 1996–1997 这段**各省不一**（12% / 16% / 其他），**未查全，本轮不启用**。

## 五、结论

1. **「引擎高估 10%」彻底作废**。171,463.29 是缴费本金，不是储存额，两者没有可比性。
2. **真实偏差是低估 1.77%（3,852.66 元 / 27.72 元·月）**，根因是吉林 1995-07~1998-06 记 16%、1998-07~2003-12 记 11%，而引擎一刀切 8%。
3. **吉林 8% 起点是 2004-01-01 不是 2006-01-01**——这条如果不纠正，2004/2005 两年会**反向多记** 365 元。
4. 全国推广需按三批次配置（辽 2001-07 / 吉黑 2004-01 / 其余 2006-01）。

## 六、遗留

1. 1996–1997 段各省比例不一（辽 12%、吉 16%），未查全 ⇒ 本轮**不启用**，维持 8%。
2. 引擎侧是否改成分省 `account_rate_schedule`，待用户拍板（会改变 185 条 case 的个账/总额基线）。
3. 2009–2011 灵活就业是否 20% 全额自缴，仍是从 H=0 推断，非直接证据。
