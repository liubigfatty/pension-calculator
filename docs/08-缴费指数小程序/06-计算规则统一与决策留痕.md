# 缴费指数小程序 · 计算规则统一与决策留痕

> 文档目标：把「本人平均缴费指数小程序（全国 31 省版）」的计算口径、边界处理、校准标志等**已拍板规则**集中留痕，作为后续实现、测试、审计的唯一依据。
> 状态：**v2 已修订（2026-08-15 四方印证推翻 v1 两项铁律）**。v1 原"已批准"两项铁律经 31 省官网正式文件比对证实与官方公式相反，已据实更正；v1 旧文保留于文末「附·口径反转留痕」供审计。
> 留痕日期：v1 2026-07-09（口径决策）；v2 2026-08-15（官网四方印证修订）。

## 0. 总览（六条铁律 v2）

1. 分母口径 = **31 省统一**：当年缴费工资 ÷ **当年使用的社平基数**（2024 年缴费 ÷ hist[2024] = 2023 统计年社平）；原「陕西/西藏 = 当年统计年社平」特例 **2026-09-20 已废**
2. 视同年进指数分母 = **逐省开关**（20省进 / 11省不进；双指数省 transIndex 独立）
3. 单年指数**封顶 3.0 / 保底 0.6**（沪分段、蒙封底1、渝上限2-3、桂<1按1、黑未缴0.6 为省特例）
4. 断缴年处理遵循 **GAP_ZERO_PROVINCES**（京/津/陕/浙/云 5省）
5. 缺失年（无社平 / 未缴费）有明确处置
6. **verified_count** 为省数据校准信心标志，随数据包下发

---

## 规则① 分母口径：31 省统一 = 当年缴费工资 ÷ 当年使用的社平基数

- **规则正文**：第 i 年平均缴费指数 aᵢ = 当年月均缴费基数 ÷ **上一年度**全省职工月社平工资（Aᵢ₋₁）。平均指数 = Σ(aᵢ × 当年月数) ÷ Σ(当年月数)（按月加权）。
- **2026-09-20 修订**：取消陕西/西藏「当年统计年社平」特例，**31 省一口径**。判据：按下限缴费者指数应恰好 = 0.6，实测陕西 4650÷0.6 = 7750 ✅、西藏 7066.2÷0.6 = 11,777 ✅（原口径下分别为 0.60→0.5483、0.6152，自相矛盾）。引擎 `denom:'current'` 分支保留但已无省份使用。
- **决策**：默认取 `avg_salary_history[year-1]`；`except_current_year_salary = {shaanxi, xizang}` 时取 `[year]`。
- **来源（四方印证·官网）**：上海人社官方问答"实际月缴费基数÷对应的**上年度**全市社平"；北京183号令"当月均缴费工资÷**上年度**当地在岗社平"；广东粤府〔2006〕96"月缴费工资÷**上年度**全省社平"；山东鲁政发〔2006〕92"1996缴费基数÷1995年度省社平"；云南云政发〔2006〕139"建账第一年缴费工资÷建账**上年度**社平"；陕西陕政发（当年社平异类）；西藏藏政发〔2006〕37（当年社平异类）。
- **理由**：国发〔2005〕38号及 31 省配套文件绝大多数采用"缴费工资÷上一年度社平"口径。v1 的"当年社平"结论（2026-07-09）已推翻；原判定的陕/藏"当年"亦于 2026-09-20 统一，详见文末附。

## 规则② 视同年进指数分母：逐省开关（D2 两阵营）

- **规则正文**：平均指数分母是否包含"视同缴费年限"，**逐省不同**，不可一刀切：
  - **进分母（20省）**：平均指数 = (Σ实际年指数 + 视同年×视同指数) ÷ (实际缴费年 + 视同年)。视同指数默认 1.0；广东=查表(sight_index_map)；浙江=替代指数≈1.279(市/时段，待建表)；江苏1991前分段联动。代表：沪/粤/京/浙/津/苏/晋/吉/宁/皖/闽/桂/黔/琼/冀/豫/云/赣/湘/鄂。
  - **不进分母（11省，N=实缴）**：平均指数 = Σ(实际年指数) ÷ N实缴；视同年只计入养老金公式的"缴费年限(含视同)"乘子，不进指数分母。代表：陕/渝/甘/黑/辽/鲁/川/藏/新/青/蒙。
  - **双指数/双基数省（晋/京/津/苏/吉 + 辽）**：基础养老金用含视同的 avgIndex；过渡性养老金用独立 transIndex（建账前实际段，视同年默认1.0；吉/辽建账前实缴用市州+全省双基数加权）。transIndex 由引擎另算供主程序过渡性公式。
- **决策**：以省级开关 `sight_year_in_avg`（21省 true / 10省 false）+ `dual_index`（6省 true）驱动；视同年由 `account_start`/`cutoff_date` 推算。
- **来源（四方印证·官网）**：上海"指数含视同年限，视同年指数按1"；广东"平均指数=(视同指数×视同月+实际指数和)÷(视同月+实际月)"；云南"[(1×视同缴费年限+Σ实缴年指数)÷累计缴费年限]"；山东鲁政发92"平均指数=1996后实缴段指数和÷实缴年（视同年不进）"；四川川劳社发17"N=实际参保缴费年限（不含视同）"。
- **理由**：v1 隐含"视同年不进分母"且未做省开关，对 21 省（视同年进分母省）平均指数口径与官方核定表不符。已据实改为逐省开关。

## 规则③ 封顶保底：单年指数 ∈ [0.6, 3.0]（省特例如下）

- **规则正文**：每一年 aᵢ 默认 clamp 到 [0.6, 3.0]；超出按边界计。
- **省特例（D5）**：上海=分段保底（93–10 <1 按1，11/12/13 年 ≥1/0.85/0.75）；内蒙古=过渡性封底1（index_floor_one，已据内政办字〔2006〕253号确认）；重庆=指数上限 1993–97 为2、98后为3；广西=建账前实际<1 按1；黑龙江=未缴费年指数按0.6（不记0）。
- **决策**：`aᵢ_clamped = min(3.0, max(0.6, aᵢ))`，省特例经 `province_cap_floor` 覆盖。仅作用于平均指数分子/分母，不影响个人账户入账（入账用实际基数×8%）。
- **来源**：`index-mini/AGENTS.md:27`；P0-1 缺失见 `07-P0修复规格.md`。
- ✅ **通用 [0.6, 3.0] 夹取已废除（2026-09-21 已落地，v2.3.0）**：60%/300% 是**缴费端基数核定口径**（国办发〔2019〕13号），**不是计算端规则**。判据=有无文件明文「计算指数时低于 X 按 X」：
  1. **合规数据天然在区间内**：实测 30 省按参保地 60%/300% 档缴费者，raw 恰好 = 0.6000 / 3.0000，夹取为恒等变换（脚本 `_audit_cap_necessity.js`）。
  2. **跨省流动夹取即篡改国家算法**：国办发〔2009〕66号「以本人在**各参保地的缴费工资**和**待遇领取地相对应各年度职工平均工资**计算缴费工资指数」⇒ 参保地下限按参保地社平核定、分母却是退休地社平，指数**必然**跑出区间，这是制度既定结果（如江西 60% 档 → 上海退休 = 0.3149，旧逻辑被夹成 0.6000，虚增 93%）。
  3. **静默夹取会掩盖输入错误**：年缴费额误当月基数（×12）→ raw 7.2 被静默改成 3.0；月基数误当年基数（÷12）→ raw 0.05 被改成 0.6。用户拿到"看起来正常"的错误结果。
  → **已落地**：`applyCap()` 仅保留**省级明文计算端规则**（沪 1993–2013 分段保底、渝上限分段、桂建账前<1按1、黑未缴费年 0.6、粤 a 系数），其余 29 省**直接返回实际比值**；删除 `CAP_EFFECTIVE`/`capRatio()`/`mixByCapRatio()`；上海 2014 起 `shanghaiFloor()` 返回 null（无明文）。
  → **超区间不改数值，只暴露**：`yearsDetail` 增 `indexRaw`/`outOfRange`，顶层返回 `warnings[]`；前端逐年清单高亮 + 文案区分「跨省流动属正常」与「请核对缴费基数」。
  → 影响：60%/100%/300% 档**零变化**；40% 档 0.6000 → **0.4000**；500% 档 3.0000 → **5.0000**；跨省流动按国家口径修正。⚠️ 连带：广东 a 系数首次真正生效（此前因先 clamp 导致 a 恒 = 1）。

## 规则④ 断缴年（gap year）处理：GAP_ZERO_PROVINCES

- **规则正文**：北京 / 天津 / 陕西 / 浙江 / 云南 5 省，计算平均指数时用"应缴费年限"作分母，断缴年计入分母、分子按 0 计（该年 aᵢ = 0），稀释平均指数；其余省断缴年直接忽略（不进公式）。重庆断缴**不计**分母；黑龙江未缴费年按 0.6 而非 0。
- **决策**：`GAP_ZERO_PROVINCES = {beijing, tianjin, shaanxi, zhejiang, yunnan}` 唯一判定集合（与 v1 一致）。
- **来源**：`index-mini/cloudfunctions/calcIndex/index.js:13`（硬编集合）；前端 `pages/index/index.js:64` 重复用于展示。
- **已知代码缺口（H1）**：`calcIndex.js:101` 的 `isGapYear` 缺 upper bound，退休后年份可能误判断缴；修复见缺陷单。
- **云南注意**：云南同时"视同年进分母"(规则②=true) 且 GAP_ZERO=true，断缴年计入分母记0，视同年计入分母记1.0，二者叠加。

## 规则⑤ 缺失年处理（无社平 / 未缴费）

- **规则正文**：
  - (a) 某年无社平数据：该年从平均指数公式剔除（不进分子、不进分母），`yearsDetail` 记 `index:null`。
  - (b) 用户未缴费年（baseAvg=0）：GAP_ZERO 省计入分母(aᵢ=0)；非 GAP_ZERO 省识别为断缴排除；黑龙江未缴费年按0.6。
  - (c) 真实低基数年：按实际值计算，再经规则③保底到 0.6。
- **决策**：前端契约——逐年明细只发应覆盖缴费年，断缴年 baseAvg=0 由 GAP_ZERO 标志决定计入与否。
- **来源**：`calcIndex.js:132-140`（社平缺失剔除）、`:144-148`（加权累加）、前端 `pages/index/index.js:125-128`。

## 规则⑥ verified_count：省数据校准信心标志

- **规则正文**：`verified_count` = 该省 `avg_salary_history` 中已由人工对照官方来源核对的**年数**。0/缺失=未核实。
- **决策**：随社平数据包下发（小程序/网页端），结果页提示"该省社平已核对 N 年/尚未核对"；信心标志，不改变计算。
- **来源**：`cloudfunctions/calculate/provinces/*.json` 顶层 `verified_count`（henan=7 最高；13省>0、7省=0、11省缺失含 jilin）。
- **理由**：全国社平多为手工录入，用户正逐省核对；用 `verified_count` 让终端判断可信度。

- **v1 铁律①（2026-07-09 决策，已推翻）**：分母=当年社平·月加权，金标准 1.6238（吉林样本）。**v2 更正**：分母=上年度社平（陕/藏例外当年）。依据：31 省官网文件明示"缴费工资÷上一年度社平"，v1 将"官方公式字面 aᵢ/Aᵢ"误读为当年，实际 Aᵢ 在各省配套文中即"上一年度社平"。
