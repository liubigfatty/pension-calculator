## 二、怎么跑的（消除社平高低的干扰）

各省社平差好几倍，直接套同一笔钱没有可比性。所以做了**归一化**：

```
段的缴费基数'  =  该段在吉林的指数  ×  该省该段的等效社平
```

即：**假设这个人在每个省都按同样的相对档位缴费**。剩下的差异**只来自算法**。

⚠️ 归一化必须**精确到段**（走引擎自己的 `buildYearSegments` + `getDenominator`）。用「年度等效社平」近似时，7-6 式省份（粤沪鄂吉）会引入 ±0.005 的噪声——第一版就踩了这个坑，吉林自己算出 1.2282（真实值 1.2330）。改成段级后吉林回到 **1.2330，与真实值逐位一致**。

同时给一列「按月加权基准」：临时摘掉该省的 `INDEX_WEIGHT_RULES`（保留 `PROVINCE_RULES` 的 cap / denom / gapZero），得到「同省配置 + 按月加权」的对照值 ⇒ Δ% 即该省特殊算法的净影响。

## 五、结论

**各省的真实分歧不来自「档位」本身，而来自四件事：**

1. **断缴年**按整年进分母（B 档，权重 1.0）还是按实缴月数加权（A 档，权重 = 月数）
2. **退休当年**算不算（7 省明文不算：吉辽冀甘宁琼皖）
3. **省级保底 / 封顶**（上海 floor 1.0、广西建账前 1.0、重庆上限 3.0）
4. **hist 缺年导致整年作废**（数据缺口，不是算法问题）
